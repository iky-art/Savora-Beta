# 💚 Savora

> Smart Personal Finance & Savings Tracker

Savora adalah aplikasi pencatat keuangan modern yang membantu pengguna mengelola pemasukan, pengeluaran, tabungan, dan target keuangan dengan antarmuka yang sederhana, cepat, dan responsif.

---

## ✨ Features

- 💰 Dashboard Keuangan
- 📥 Pencatatan Pemasukan
- 📤 Pencatatan Pengeluaran
- 🏦 Manajemen Tabungan
- 🎯 Target Menabung
- 📊 Statistik Keuangan
- 🔍 Pencarian Transaksi
- 🏷️ Kategori Transaksi
- 🌙 Dark Mode
- 📱 Responsive Design
- ⚡ Fast Performance
- 🖼️ SVG Icons
- 📦 PWA Ready
